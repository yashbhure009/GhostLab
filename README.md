# Ghost-Lab

**A local privacy firewall that sits between you and AI tools.**

Students and professionals unknowingly leak sensitive data every time they use AI platforms — names, emails, phone numbers, and personal identifiers get sent directly to the cloud with no filtering. Ghost-Lab solves this by running entirely on your machine. It intercepts your input before it leaves the browser, replaces sensitive information with realistic synthetic data, sends only the safe version to external AI systems, and restores your original data when the response comes back — so privacy and usability are both preserved.

---

## How it works

1. You type a prompt containing personal information into any supported AI platform.
2. The browser extension detects the text and sends it to the local Ghost-Lab backend.
3. The backend identifies PII (names, emails, phone numbers) using Microsoft Presidio and replaces each one with a realistic fake generated by the Faker library.
4. The sanitized text is what gets sent to the AI platform — your real data never leaves your device.
5. When a response comes back, Ghost-Lab swaps the fake values back to the originals locally.

## Tech stack

| Layer | Technology |
|---|---|
| Browser extension | JavaScript (Manifest V3) |
| Backend API | Python, FastAPI |
| PII detection | Microsoft Presidio Analyzer |
| Fake data generation | Faker |
| Local mapping store | In-memory Python dict |
| CORS | FastAPI CORSMiddleware |

## Requirements

- Python 3.9 or higher
- Google Chrome or any Chromium-based browser
- pip

Python dependencies:

```
fastapi
uvicorn
presidio-analyzer
presidio-anonymizer
faker
spacy
```

You also need the spaCy English model that Presidio uses:

```
en_core_web_lg
```

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/yashbhure009/GhostLab
cd ghost-lab
```

### 2. Install Python dependencies

```bash
pip install fastapi uvicorn presidio-analyzer presidio-anonymizer faker spacy
```

### 3. Download the spaCy language model

```bash
python -m spacy download en_core_web_lg
```

### 4. Load the Chrome extension

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (toggle in the top right)
3. Click **Load unpacked**
4. Select the `ghostlab-extension` folder from this repository

---

## Running the backend

From the root of the project, run:

```bash
uvicorn Backend.main:app --reload
```

The API will start at `http://127.0.0.1:8000`.

You can verify it is running by visiting:

```
http://127.0.0.1:8000/
```

Expected response:

```json
{
  "Ghost Lab": "RUNNING",
  "message": "Welcome to the Ghost Lab API!"
}
```

## API reference

### POST `/analyze`

Accepts user input, anonymizes PII, runs it through the AI layer, and returns the result.

**Request body:**

```json
{
  "text": "My name is John and my email is john@example.com",
  "known_fakes": ["Alice Johnson", "5551234567"]
}
```

`known_fakes` is a list of values already substituted in a previous request. The backend skips these so they are not anonymized a second time.

**Response:**

```json
{
  "original_input": "My name is John and my email is john@example.com",
  "sanitized_sent_to_ai": "My name is Alice Johnson and my email is fake@mail.com",
  "ai_output": "AI processed: My name is Alice Johnson and my email is fake@mail.com",
  "final_output": "AI processed: My name is John and my email is john@example.com"
}
```

## Notes

- The mapping between fake and real values is stored in memory. Restarting the backend clears it.
- The extension stores known fake values in `localStorage` per browser session, so values are not re-anonymized on subsequent keystrokes.
- `ai_mock.py` is a placeholder. Replace `run_ai()` with your actual API call to connect to a real language model.
